00Before you start

Do these four things once, on any page, before you open a single widget. Everything after this sheet assumes they are done.

  1. Install Plus Jakarta Sans. Elementor does not ship it. Either enable Google Fonts under Elementor › Settings › Features and pick it in any font dropdown, or upload the family under Elementor › Custom Fonts. You need weights 400, 500, 600, 700, 800 — the design uses all five.
  2. Turn off the theme's own styling. Elementor › Settings › General → tick Disable Default Colors and Disable Default Fonts. Without this your theme fights every value on this sheet.
  3. Set Global Colors and Global Fonts first (panels 01 and 02). Everything afterwards should point at those globals, never a raw hex typed into a widget. Then a brand tweak is one edit instead of two hundred.
  4. Use Containers, not Sections. Elementor › Settings › Features › Flexbox Container: Active. The layout is CSS grid and flex throughout — containers map to it one-to-one, legacy sections do not.

About the three values on each size

The site sizes type fluidly with clamp(). Elementor's fields take one number per device, so every size here is given as Desktop / Tablet / Mobile — measured at 1440 px, 900 px and 390 px, which is where those breakpoints actually land. Enter all three; the middle one is the one people forget.

Weight 600 and 500 have exactly one job

Alternate your section backgrounds

No Elementor Pro? Custom CSS is a Pro feature

Paste the same block into Appearance → Customize → Additional CSS, or into your child theme's style.css. The class names work identically — only the place you paste it changes.

Once it is in, any Elementor colour field accepts var(--gold), and any size field accepts the values on this sheet.
